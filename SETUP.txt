# Sakthi Kumar — GitHub Profile README

## Publishing Guide

1. **Repository Configuration**:
   - Ensure the repository name is exactly `sakthikumar-1` (matching your GitHub username `sakthikumar-1`).
   - GitHub automatically recognizes this repository as your **Special Profile README** and displays it prominently on your main profile page (`https://github.com/sakthikumar-1`).

2. **Asset Structure**:
   - The visual assets (`sakthi-hero.png`, `technology-map.svg`, and `workflow.svg`) are stored in both the repository root and the `assets/` directory.
   - This ensures 100% path resolution and zero broken image links regardless of whether GitHub or a Markdown previewer queries the root or the `assets/` subfolder.

3. **Live Widgets & Dynamic Statistics**:
   - Dynamic typing SVG: Animated live greeting banner via `readme-typing-svg`.
   - Real-time GitHub Analytics: Fetches real-time commits, streaks, and top languages.
   - Profile Views Counter: Increments dynamically upon profile visits.
